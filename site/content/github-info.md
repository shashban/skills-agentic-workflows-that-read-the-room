## Recent updates worth watching

### From the GitHub Changelog (October 2026)

- **Stacked pull requests are generally available** (Oct 6): break big changes into smaller, reviewable PRs that build on each other. Source: [GitHub Changelog](https://github.blog/changelog/).
- **Local sandboxing for GitHub Copilot is generally available** (Oct 7): run Copilot agent work with tighter local isolation. Source: [GitHub Changelog](https://github.blog/changelog/).
- **GitHub Actions workflow lockfiles in public preview** (Oct 14): a step toward more reproducible, reviewable workflows. Source: [GitHub Changelog](https://github.blog/changelog/).
- **Agentic autofix for code scanning alerts and AI Scan for pull requests are generally available** (Oct 15). Source: [GitHub Changelog](https://github.blog/changelog/).
- **Heads-up:** some Git over HTTPS operations may temporarily require authentication (Oct 19), and selected Copilot models are being deprecated in mid-November. Source: [GitHub Changelog](https://github.blog/changelog/).

- The [GitHub Blog](https://github.blog/latest/) is the place for in-depth Copilot, Actions, and security guides; check its Copilot and GitHub categories for tutorials that complement the changelog items above.

### From Awesome Copilot workflows

Ready-made agentic workflow examples to learn from, from [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/):

- `daily-issues-report` – summarize repository issues each day.
- `weekly-comment-sync` – keep comments in sync weekly.
- `relevance-check` / `relevance-summary` – check and summarize whether content is still relevant.
- `ospo-*` (contributors report, org health, release compliance checker, stale repos) – open source program office reporting.
